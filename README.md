# AnubhiCreation World

Personal art portfolio website for Anubhi.

## Contact
- Instagram: https://www.instagram.com/anubhicreation_world
- Email: anubhicreation@gmail.com

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `anubhicreation_world` under `anubhisharma9`.
2. Upload all files and folders from this project.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Your site will be available at:
   `https://anubhisharma9.github.io/anubhicreation_world/`

## Add more artwork
Put new images in `assets/art/` and add an entry to the `artworks` array in `index.html`.
